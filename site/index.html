Live walkthroughs for RetroArch players

Retro Companion is a free Windows program. It reads the game you are playing in RetroArch and follows your progress. The walkthrough and a map stay in small windows above the game.

Each game comes as a plugin with its own walkthrough and achievements. The first one is Dragon Warrior. More games are coming soon.

What it does

A walkthrough that follows the game

The app reads the game's memory and ticks off a step when you finish it. In Dragon Warrior it notices when you find the Fairy Flute or beat the Golem.

Map and route

A live map shows where you are. It draws the way to the next goal, across towns and dungeon floors.

Battle details

In a fight you see the enemy's HP and the damage both sides can do. It also shows how likely SLEEP is to work on that enemy.

Windows above the game

Each part is a small window of its own. You can move each window and change its size. Folded, it shows only its title bar. The windows stay above RetroArch in windowed fullscreen.

Achievements and trophies

Every game has its own achievements, and each one is also a trophy graded by its points. Finishing all achievements of a game earns its platinum trophy.

Levels and a points shop

Points from every game add up to your level. You can spend them in the app on colour themes and an extra overlay window.

Account and leaderboard

With a free account your trophies follow you to any computer you sign in on. The leaderboard below lists every player's points.

Game library

The library keeps play time and progress for each game. With your own MobyGames API key it also shows release dates and descriptions.

First game: Dragon Warrior

The NES original from 1989. The walkthrough has 32 steps from the throne room to the Dragonlord, and the game has 50 achievements worth 940 points.

You need your own copy of the game. On first start the app asks for the ROM file and reads the maps and monster tables from it.

The download is on the project's release page on GitHub. The file is built there from the public source, and its SHA-256 is listed next to it. The program is not signed yet. If Windows says “Windows protected your PC”, click More info, then Run anyway.

Why it is free

I play these old games myself. I built the features I wanted for my own playthroughs, and I thought others might want them too. So the program is free for anyone.

Kemény Gergely

Support the project

Each new game needs its own memory map and a walkthrough checked against sources. That takes time. The server behind the accounts and the leaderboard has to be paid every month.

Support pays for this work and lets me add more games and features. If enough people chip in, I could work on Retro Companion full time. Later I would also like to bring it to other platforms, where the technology allows.

The program stays free for everyone. Supporters get their name on the supporters list, a mark on the leaderboard and a vote on the next game.
